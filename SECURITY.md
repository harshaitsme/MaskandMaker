# Security Policy

As this is a Flutter UI demonstration app, it does not handle sensitive user data, authentication, or backend connections. However, we take the security of the repository and its dependencies seriously.

## Supported Versions

Only the latest release is actively monitored for security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to the maintainers directly or open a private issue in this repository. We will acknowledge your report within 48 hours and provide regular updates until the issue is resolved.

Please do not disclose the vulnerability publicly until it has been addressed.
